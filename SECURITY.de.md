# Sicherheitsrichtlinie

Bitte melden Sie Sicherheitslücken **nicht** in öffentlichen Issues.

Melden Sie sie vertraulich über GitHub: *Security → Report a vulnerability* in
diesem Repository. Sie erhalten innerhalb weniger Werktage eine Antwort; Korrekturen
werden so schnell wie möglich veröffentlicht und in einem Security Advisory angekündigt.

Unterstützte Versionen: die neueste Version.

Wie das Projekt auf Schwachstellen prüft: [docs/de/developer/security-testing.md](docs/de/developer/security-testing.md).
