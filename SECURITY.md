# Security policy

Please do **not** report security vulnerabilities in public issues.

Report them privately via GitHub: *Security → Report a vulnerability* in this
repository. You will get an answer within a few working days; fixes are
released as soon as possible and announced in a security advisory.

Supported versions: the latest release.

How the project tests for vulnerabilities: [docs/developer/security-testing.md](docs/developer/security-testing.md).
